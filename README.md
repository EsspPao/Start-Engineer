# CommandDeck Next

CommandDeck Next is a minimal Windows desktop launcher built with Electron, React, TypeScript, and Vite.

## Commands

```powershell
npm install
npm run typecheck
npm run build
npm run dev
```

## Features

- Manage common games and apps in one clean launcher.
- Add `.exe` files through the native Windows file picker.
- Launch apps, terminate matched process trees, and monitor CPU, memory, and PID.
- Save the app list to Electron's user data directory.
- Drag the frameless window from the title bar or empty background regions.

# Start Engineer v0.1.3 · 公开测试版

本次主要改善分组管理的使用体验。

## 更新内容

- 修复分组拖动排序后自动回到原位的问题，右键上移 / 下移的顺序也能正确保存。
- 删除空分组不再弹出迁移窗口；有应用的分组仍会要求选择迁移目标。
- 保留最后一个分组的删除保护。

## 下载与更新

- **Setup**：安装版。退出 Start Engineer 后运行安装包更新。
- **Portable**：便携版。退出 Start Engineer 后替换旧 EXE。
- **SHA256SUMS.txt**：用于校验以上两个文件。

配置继续保存在当前 Windows 用户数据目录。此版本没有应用内自动更新，需要手动下载。

## 测试版说明

- 支持 Windows 10 / 11 x64。
- 当前未进行商业代码签名，Windows SmartScreen 可能提示来源未知；请确认下载来源及 SHA-256，不建议关闭系统安全防护。
- 部分应用的托盘窗口无法自动恢复；微信、Notion 隐藏到托盘后请手动打开。
- 批量关闭可能丢失未保存内容，请先保存工作。

遇到问题请在 [Issues](https://github.com/EsspPao/Start-Engineer/issues) 提供应用名称、操作步骤和截图。分享诊断信息前请检查并隐藏个人路径。

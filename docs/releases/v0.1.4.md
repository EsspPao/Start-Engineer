# Start Engineer v0.1.4 · 公开测试版

本次修复应用退出后仍显示绿灯的进程误判问题，建议旧版本用户更新。

## 更新内容

- 修复旧进程编号被其他程序复用后，仍被当作原应用运行的情况。例如 Akari 已退出，却误匹配到 Steam 服务。
- 关联进程必须通过名称或应用目录路径校验，不再只信任编号；失效会话关联会被清理。
- 关闭应用前使用最新受管进程快照进行同样的关联校验，避免本次错误关联进入关闭目标列表。
- 保留已确认的同目录子进程支持。

## 下载与更新

- **Setup**：安装版。退出 Start Engineer 后运行安装包更新。
- **Portable**：便携版。退出 Start Engineer 后替换旧 EXE。
- **SHA256SUMS.txt**：核对两个 EXE 的 SHA-256。

配置仍保存在当前 Windows 用户数据目录，无需重新添加应用。暂不支持应用内自动更新。

## 使用提醒

- 支持 Windows 10 / 11 x64，当前为公开测试版。
- 安装包尚未进行商业代码签名，Windows SmartScreen 可能提示来源未知；请确认下载来源和校验和，不要关闭系统安全防护。
- 部分托盘应用仍需手动唤起；关闭应用前请保存未保存内容。
- 问题反馈：[GitHub Issues](https://github.com/EsspPao/Start-Engineer/issues)。分享诊断信息前请隐藏个人路径。

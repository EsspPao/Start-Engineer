# 小黑盒介绍草稿

## 标题

给常用软件安个家：我做了一个能分组、合并卡片的 Windows 启动台

## 正文（配图位置发布时替换为实际截图 / 动图）

桌面快捷方式越堆越多，玩游戏、办公时又总要来回找软件。

所以我做了 **Start Engineer**：把常用游戏和软件收进一个启动台，按自己的习惯整理，打开电脑后少翻几个窗口。

【图 1：完整主界面，展示游戏 / 办公 / 工具分组】

**分类放好，点开就用。**
支持自定义分组；把 EXE 或快捷方式拖进来，就能添加。

【图 2：拖入应用 → 移动分组，短动图】

**经常一起用的软件，收进同一张卡片。**
拖到一起即可合并，展开后单独打开，也能批量启动。

【图 3：合并卡片 → 展开 → 批量启动，短动图】

**不想翻分组？直接搜。**
Ctrl+F 搜索，回车添加或打开。绿灯表示应用正在运行，还能按分组批量关闭——记得先保存文件。

【图 4：搜索添加 + 运行状态，左右对比图】

**喜欢桌面壁纸，也不用把它挡住。**
提供玻璃与透明主题，让启动台融入你的桌面。

【图 5：同一壁纸下 Wallpaper Glass / Clear Desktop 对比】

目前是 **v0.1.2 公开测试版**，支持 Windows 10 / 11 x64，提供安装版和便携版，无需注册账号。

下载：https://github.com/EsspPao/Start-Engineer/releases/tag/v0.1.2

提前说明：安装包暂未签名，Windows 可能提示来源未知；部分托盘应用还需手动唤起，也暂不支持自动更新。

欢迎试试。如果有哪里不好用，评论里告诉我「哪个软件 + 怎么操作 + 出了什么问题」，我继续改。

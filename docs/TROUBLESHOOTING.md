# 故障排查

## Windows 提示未知发布者

当前预览版尚未进行商业代码签名。只从本仓库 Releases 下载，使用同一 Release 的 `SHA256SUMS.txt` 核对文件；来源不明时不要运行。

```powershell
Get-FileHash .\Start-Engineer-Setup-0.1.0.exe -Algorithm SHA256
```

## 无法拖入 EXE 或 LNK

Windows 不允许把普通权限资源管理器中的文件拖到管理员窗口。Start Engineer 的主界面设计为普通权限运行；若任务管理器显示它被管理员启动，请退出后正常双击运行。普通应用会先按普通权限关闭；只有目标仍在运行时才会请求 UAC，并在授权后通过受限会话 helper 完成关闭。

## 应用启动失败

1. 右键卡片，检查程序路径和启动参数。
2. 确认 EXE 未移动或被安全软件隔离。
3. 若程序自身要求管理员权限，接受启动时的 UAC 请求。
4. 仍失败时，在“设置 → 关于与诊断”复制诊断信息并创建 Issue；不要上传个人配置文件。

## Microsoft Store 应用更新后无法启动

新版会通过稳定 Windows 应用标识启动 Store / MSIX 应用，并自动修复旧的版本化 `WindowsApps` 路径，无需手动重新选择 ChatGPT 等应用的 EXE。若提示“未找到对应的 Windows 商店应用注册”，请先在 Windows“已安装的应用”中确认该应用仍存在；卸载后残留的卡片不会被误当作普通路径重新绑定。

## 正在运行但无法唤起窗口

部分托盘应用、启动器和多进程程序不公开普通顶层窗口。右键应用查看窗口列表或复制窗口诊断；必要时直接从系统托盘恢复。

## Everything 搜索不可用

在设置的“搜索依赖”中刷新状态或重新准备。下载校验失败时不会解压文件；检查网络后重试，或手动安装 Everything 并选择官方 `ES.exe`。

## 重置配置

先退出 Start Engineer，再备份并重命名 `%APPDATA%\start-engineer`。重新启动会创建默认配置。该操作会移除应用列表、分组、偏好和图标缓存。

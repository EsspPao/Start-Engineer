# 干净环境验收记录（2026-09-25）

本轮使用 Windows Sandbox（Windows 11，10.0.26100，x64）和独立临时配置验证公开体验前的安装、启动、配置与恢复。沙盒关闭网络，并将 `release/` 只读映射到来宾；验收结果写回隔离目录。待测包是本地 v0.1.4 重打包产物，尚未发布到 GitHub。

## 已通过

- 本地 `npm run release:verify`：108 个测试文件 / 525 项测试、TypeScript 类型检查、生产构建、原生 helper 冒烟（196 个快捷方式）和 Electron 生产启动冒烟通过。
- 本地安装版与便携版重新生成至 `release/`，SHA-256 清单与实际文件一致，安装版约 83 MiB、便携版约 82.75 MiB。
- 沙盒第一轮：静默全新安装成功，安装目录中的 `Start Engineer.exe` 存在；安装版启动输出 `START_ENGINEER_SMOKE_READY`，说明 Electron 渲染进程已就绪。
- 独立 Electron 进程重新启动验证配置恢复：原有分组恢复、备份后的新分组消失，自动升级备份与恢复前安全备份均保留。
- 设置页在 1440×800、1024×600 两种窗口尺寸完成实际渲染回归；反馈草稿只附带版本/构建/系统信息，不附个人路径；手动备份和取消恢复可用。

## 尚需补齐的验收

- 沙盒第一轮脚本在读取安装版进程退出码时失败，未继续执行便携版启动与卸载。该失败发生在渲染就绪标记之后，不能据此认定应用启动失败；也不能将便携版和卸载标记为通过。后续两次复跑沙盒未完成启动，没有生成新的验收结果，已关闭复跑进程。
- 主机上的便携包冒烟复测两次均触发 `Start Engineer.exe` 的 Windows 异常 `0x80000003`，一次在旧实例运行时、一次在完全关闭旧实例后。后一次仍复现，因此不能归因于多开冲突。旧烟测在网页加载后仅延迟 100 毫秒便退出，可能在渲染和子进程仍初始化时提前关闭。现已改为收到 React 挂载信号后输出就绪标记，延迟 1 秒退出；类型检查、525 项单元测试、构建和重新打包通过，但**新包尚未隔离启动复验**，不能宣称异常已修复。已停止继续在用户桌面启动以免再次弹窗。此项应在公开发布前解决。
- 未在 Windows 10、SmartScreen / 未签名安装提示、安全桌面 UAC、真实用户升级流程和鸣潮 Alt+F4 新版本实机体验中验收。配置备份通过独立进程恢复回归，鸣潮进程识别通过记录与单元回归。

## 来源与边界

- 沙盒配置和脚本保存在忽略的 `node_modules/.cache/sandbox-validation/`，无网络、只读访问安装包；不会带入用户当前配置。
- 最终对外发布前，应以实际发布包再做一次安装、首次启动、便携版、升级及卸载人工验收，尤其检查 Windows 的未签名提示和 UAC 文案。
